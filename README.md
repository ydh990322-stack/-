# 🍼 맘앤대디 라운지

육아하는 엄마·아빠들을 위한 커뮤니티 홈페이지입니다.
**정보 공유 · 소통 · 매주 이벤트 · 친구 초대(입소문) · 포인트 → 상품 교환 / 현금 출금**까지 한 번에 동작합니다.

## 빠른 실행

```bash
npm install
npm start          # http://localhost:3000
npm test           # API 테스트 (가입/추천/출석/게시판/이벤트/상점/출금)
```

- Node.js 22.13 이상 필요 (내장 SQLite 사용 → 별도 DB 설치 불필요, `data/community.db` 자동 생성)
- 최초 실행 시 관리자 계정 생성: `admin@momdad.kr` / `admin1234!`
  → **운영 전 반드시** `ADMIN_EMAIL`, `ADMIN_PASSWORD` 환경변수로 바꿔서 실행하세요.

| 환경변수 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | 3000 | 서버 포트 |
| `SITE_NAME` | 맘앤대디 라운지 | 사이트 이름 |
| `DB_FILE` | `data/community.db` | DB 파일 경로 |
| `ADMIN_EMAIL` / `ADMIN_PASSWORD` | — | 최초 관리자 계정 |

## 주요 기능

### 회원 / 커뮤니티
- 회원가입(아이 연령대·지역), 로그인
- 게시판: 공지 · 육아정보 · 자유수다 · 질문답변 · 육아템리뷰 · 지역모임
- 검색, 최신/인기순 정렬, 댓글, 공감, 이번 주 인기글, 이번 주 활동왕 랭킹
- 모바일 하단 탭바 지원 (반응형)

### 입소문 홍보
- 회원마다 고유 **초대 코드 / 초대 링크**
- 초대한 사람 +2,000P, 초대받은 사람 +1,000P 추가
- 게시글·이벤트 공유 버튼 (모바일은 카톡 등 기본 공유창, PC는 링크 복사) — 공유 링크에도 초대 코드가 자동 포함

### 이벤트
- **매주 정기 이벤트 자동 생성** (매주 월요일, 5가지 주제 순환)
- 관리자가 스페셜 이벤트 등록 가능
- 참여 즉시 포인트, 관리자가 **무작위 추첨 → 당첨 포인트 자동 지급**

### 포인트 제도 (`config.js`에서 조정)
| 활동 | 포인트 | 제한 |
| --- | --- | --- |
| 가입 | 1,000 | 1회 |
| 친구 초대 | 2,000 (친구 +1,000) | — |
| 출석체크 | 100 | 하루 1회, 7일 연속 +500 |
| 글쓰기 | 50 | 하루 5회 |
| 댓글 | 10 | 하루 20회 |
| 공감 받기 | 5 | 하루 20회 |
| 정기 이벤트 참여 / 당첨 | 100 / 3,000 | 이벤트당 1회 |

모든 적립·차감은 `point_transactions` 원장에 기록되고 트랜잭션으로 처리됩니다.

### 포인트샵 (상품 교환)
- 기프티콘(휴대폰 번호) / 실물 육아용품(배송 주소) 구분, 재고 관리
- 관리자: 발송 완료 처리, 취소 시 포인트·재고 자동 복구

### 현금 출금
- 1P = 1원, **10,000P부터 1,000P 단위**, 수수료 500P
- 가입 7일 이후, 하루 1회, 대기 중 신청이 있으면 추가 신청 불가
- 신청 시 포인트 즉시 차감 → 관리자가 송금 후 '입금완료' / '반려'(포인트 자동 환불)

### 관리자 페이지 (`#/admin`)
대시보드(회원 보유 포인트 = 잠재 비용 표시) · 출금 관리 · 교환 관리 · 상품 관리 · 이벤트 관리 · 회원 포인트 지급/회수

## 실제 오픈 전 체크리스트

이 프로젝트는 바로 돌려볼 수 있는 완성형 프로토타입입니다. 실제 돈이 오가는 서비스로 운영하려면 아래를 꼭 준비하세요.

1. **법률 검토** – 포인트의 현금 환급은 전자금융거래법(선불전자지급수단), 사행성 규제, 기타소득 원천징수(세법) 이슈가 있을 수 있습니다. 오픈 전 세무사·변호사 자문을 권장합니다.
2. **본인인증** – 출금 전 휴대폰 본인인증(PASS 등)과 계좌 실명확인 API를 연동해 다계정 어뷰징과 명의 도용을 막으세요.
3. **실제 송금** – 현재는 운영자가 직접 송금 후 '입금완료'를 누르는 방식입니다. 규모가 커지면 펌뱅킹/송금 API로 자동화하세요.
4. **기프티콘 발송** – 기프티콘 B2B 발송 API(예: 기프티쇼 비즈 등)를 연동하면 교환 즉시 자동 발송할 수 있습니다.
5. **이용약관·개인정보처리방침** 페이지 작성, HTTPS 적용, 정기 DB 백업.
6. **카카오톡 공유** – 카카오 개발자 앱 키를 발급받아 Kakao JS SDK를 붙이면 썸네일이 있는 공유 카드로 바꿀 수 있습니다.

## 구조

```
server.js        Express API (인증, 게시판, 이벤트, 포인트, 상점, 출금, 관리자)
db.js            SQLite 스키마, 초기 데이터, 포인트 원장 헬퍼, 주간 이벤트 자동 생성
config.js        포인트·출금 정책
public/          프론트엔드 (빌드 없는 SPA: index.html, app.js, styles.css)
test/            API 테스트 (node:test)
```
